# 图纸识别往返验收

启动开发服务后打开 `/qa/chart-import-roundtrip.html`，选择 52、78 或 104，运行 40 色测试。

该页面调用应用实际导出器生成含色号和用量的图纸，然后执行本机图例识别、网格检测和颜色映射。比较项包括每个色号的用量、网格尺寸和每一个格子。`incorrect` 应为空，`cellErrors` 应为 0；低置信度格子可以保留以供校对。

可下载验收原图，回到首页导入，验证真实向导的自动执行、总进度 Toast、分步网格检测和校对结果。页面不保存作品、不上传图像，也不作为生产入口打包。

计时只代表当前设备和生成样例，不能代表所有外部图纸、拍照图片或冷启动网络环境。5 秒超时应明确显示失败并转为手动调整，不能当作识别成功。
