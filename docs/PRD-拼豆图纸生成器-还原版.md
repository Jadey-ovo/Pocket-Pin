# Pocket Pin

> 2026-09-07 修订：手机 / Pad 浏览器定位、基础手势、单层模型、生成预览与本轮功能范围，以 [H5 编辑体验迭代](PRD-H5编辑体验迭代.md) 为准。本文保留原始还原内容供追溯。

## 1. 产品说明

Pocket Pin 是产品正式名称，用于将图片转换为 MARD 色号拼豆图纸，并提供手工编辑、材料统计和图纸导出能力。产品主要面向 Pad 和桌面端应用。两个终端提供一致的功能内容、页面结构和视觉表达，并针对触控、手写笔、鼠标和键盘采用适合各自终端的操作方式。

本文档根据参考实现的实际能力整理，供 Pocket Pin 后续调整功能范围和业务规则使用。未在参考实现中出现的账号、云端服务、社区和交易能力不属于当前产品范围。

## 2. 功能总览

| 功能模块 | 业务目标 |
| --- | --- |

| 图片生成 | 将普通图片转换为有限色数的拼豆格图案 |
| 图案编辑 | 支持逐格绘制、批量处理和图案组合 |
| 色卡管理 | 使用 MARD 色号完成选色和颜色匹配 |

| 参考图 | 为手工临摹和图案核对提供辅助底图 |

## 3. 主页

### 3.1 页面定位

主页是用户进入产品后的默认页面，负责提供新作品创建入口和最近图纸入口。主页不承载具体编辑能力，所有新建和历史图纸最终进入同一个工作区。

### 3.2 导入照片

导入照片是基于现有图片创建图纸的快捷入口。用户选择照片后，系统使用默认生成配置直接生成拼豆图，并创建一份可编辑图纸。生成完成后进入工作区，用户可使用图片生成、图案编辑、图层、色卡、调整、预览、用量和导出等全部工作区功能。

默认生成配置使用 52 格目标宽度、24 色上限、卡通风格、保留背景和 MARD 常用 211 色色卡。图案高度根据照片比例计算。

业务边界 该入口用于缩短首次生成路径，不限制用户后续调整生成参数或重新导入图片。

交互备注 用户选择有效照片后直接开始生成，无需先进入参数设置页面。生成期间需要提供明确的处理中状态，生成失败时保留重试和重新选择照片的入口。

照片生成失败或用户在生成完成前退出时，系统询问是否保留未完成图纸。用户选择保留后，项目以未完成状态保存到图纸空间。用户选择不保留后，系统二次确认并删除本次未完成内容。

### 3.3 创作图纸

创作图纸是从空白画布开始绘制的快捷入口。进入后创建默认 52 × 52 空白项目，并直接打开工作区。

空白工作区仍保留图片导入和图片生成能力。主页的两个入口只用于帮助用户理解两种主要创作方式，不形成两套不同的编辑器。

### 3.4 我的拼豆图纸

主页在两个核心功能入口下方展示我的拼豆图纸，采用双列瀑布流排列。这里展示的图纸与图纸空间使用同一份项目数据，用于快速查看和继续编辑。完整的搜索、筛选和管理能力由图纸空间提供。

每个图纸卡片至少包含图纸预览和图纸名称。用户选择图纸后进入工作区，并加载该图纸最近保存的可编辑状态。图纸修改后更新对应作品，不创建重复副本。

图纸列表按最近编辑时间倒序排列。不同尺寸的图纸预览保持原始宽高比例，使横向、纵向和正方形作品都能完整展示。

交互备注 Pad 和桌面端均保持双列瀑布流。卡片的编辑入口需要支持触控点击和鼠标点击，不得依赖悬停才能发现或执行。

### 3.5 主页空状态

用户没有历史图纸时，我的拼豆图纸区域展示空状态，并继续保留导入照片和创作图纸两个核心入口。空状态用于说明完成或保存的图纸会显示在此处。

## 4. 图纸空间

### 4.1 功能定位

图纸空间是独立的一级菜单，用于集中查看和管理用户的拼豆图纸项目。产品的一级菜单至少包含首页和图纸空间。首页负责开始创作和快速继续，图纸空间负责完整的项目查看与管理。

交互备注 Pad 端可使用底部双菜单栏展示首页和图纸空间。桌面端可根据屏幕空间使用侧边栏或顶部导航，但菜单名称、图标含义和页面内容保持一致。

### 4.2 项目列表

图纸空间展示用户已创建或保存的全部图纸项目。每个项目至少保存独立标识、名称、图纸预览、创建时间、最近编辑时间、完成状态和可编辑项目数据。

项目默认按最近编辑时间倒序排列。不同尺寸的项目预览保持图纸原始宽高比例。项目列表需要明确区分已拼完和未拼完状态。

图纸空间支持按项目名称搜索，支持按已拼完和未拼完筛选。搜索和筛选只改变当前展示结果，不改变项目数据和排序时间。

### 4.3 项目预览

用户可在不进入编辑状态的情况下查看项目预览。预览内容包括完整图纸、画布尺寸、拼豆总颗数、颜色种数和各色号消耗信息。

色号消耗信息至少包含色号、颜色、所需颗数和预计包数，统计规则与工作区用量统计保持一致。

### 4.4 完成状态

每个项目支持标记为已拼完或未拼完。完成状态由用户手工维护，不根据编辑进度、导出行为或拼豆数量自动判断。

更改完成状态只更新项目状态，不修改图纸内容、拼豆层数据和用量统计。用户可取消已拼完标记，使项目恢复为未拼完。

### 4.5 项目操作

每个项目支持进入编辑、进入预览、重命名、复制和删除。

进入编辑后加载项目最近保存的可编辑状态，并打开共用工作区。进入预览后只展示图纸和色号消耗，不允许修改项目内容。

重命名只修改项目名称。复制会创建一份拥有新标识的完整项目副本，保留图纸内容和完成状态，并以复制时间作为新项目的创建时间和最近编辑时间。

删除属于敏感操作。用户确认删除前，系统不得移除项目。二次确认需要明确展示待删除项目名称，并说明删除后的影响。用户取消确认后，项目和页面状态保持不变。

业务边界 MVP 不提供回收站。用户确认删除后，系统永久移除设备本地的项目数据，确认文案需要明确删除后无法恢复。

### 4.6 项目保存与恢复

项目变化后自动保存当前图纸，并更新最近编辑时间和项目预览。用户从首页或图纸空间再次打开图纸时，系统恢复画布、拼豆层、颜色和项目设置。

系统需要保存多份图纸。单个项目草稿损坏或不符合基本结构时，不得影响其他项目。

MVP 只使用设备本地存储，不提供账号、云端保存和跨设备同步。后续版本可在不改变项目数据结构的前提下增加云端能力。

## 5. 图片生成图纸

### 5.1 图片输入

系统支持 PNG、JPG、JPEG 和 WebP 图片。图片可通过文件选择、拖放到工作区或粘贴剪贴板导入。

导入图片后，系统展示文件缩略预览和文件信息。图片文件仅在当前浏览器会话中使用，不上传到服务端。

### 5.2 生成参数

| 参数 | 业务说明 | 默认值 |
| --- | --- | --- |
| 目标宽度 | 决定生成图案的横向格数，图案高度按原图比例计算 | 52 |
| 色数上限 | 限制生成结果中使用的拼豆颜色种数 | 24 |
| 生成风格 | 卡通优先保留主色和轮廓，写实优先保留明暗细节 | 卡通 |
| 背景方式 | 保留原图背景，或移除接近背景色的区域 | 保留背景 |
| 容差 | 控制去背景时对相近背景色的识别强度 | 32 |
| 色卡 | 决定生成结果可使用的 MARD 颜色集合 | MARD 常用 211 色 |

### 5.3 转换规则

系统将原图划分为目标拼豆格，并对每个格覆盖的原图区域进行多点采样。采样结果先用于识别候选色，再匹配到当前 MARD 色卡中最接近的颜色。

卡通模式采用更密集的单格采样和更强的主色判断，适合图标、插画和边界清晰的图片。写实模式保留更多区域平均色，适合人像和存在渐变光影的图片。

转换后，系统会整理相近颜色、微小区域和零散像素。去背景时结合透明像素、图像边缘背景色、白色阈值和用户容差识别空白格。

### 5.4 生成结果

生成图案写入唯一拼豆层，用户可以继续手工编辑。生成图案尺寸大于当前画布时，画布扩展以容纳结果。生成图案尺寸较小时，现有画布尺寸保持不变。

业务边界 拼豆层锁定时不能执行图片生成。若项目由照片快捷入口创建且拼豆层尚未被用户编辑，生成结果可直接写入。拼豆层已有手工编辑或调整结果时，重新生成会覆盖现有内容，必须先由用户二次确认并说明影响范围。

交互备注 图片或生成参数变化后约 420 毫秒自动生成。系统以请求序号识别最新结果，旧请求完成后不得覆盖新结果。

## 6. 图案编辑

### 6.1 工作区项目操作

工作区支持创建空白项目。默认创建 52 × 52 画布和一个可编辑拼豆层，拼豆层可见且未锁定。默认项目名为 `Untitled Pattern`。

用户可设置画布宽度和高度，范围为 8 至 180 格。系统提供 52 × 52、78 × 78、104 × 104、156 × 156 四种常用尺寸。改变尺寸时拼豆层同步调整，超出边界的格子被裁切，新扩展区域为空。系统按 52 × 52 拼豆板估算所需板数。

清空功能清除拼豆层中的全部拼豆格，保留项目设置和照片参考层。锁定拼豆层不能被清空。

工作区支持撤销和重做。有效修改进入编辑历史，最多保留 40 个项目快照。执行新的有效修改后，重做记录失效。

交互备注 用户修改画布宽高后需要执行应用，避免输入过程中频繁重绘。

新建项目会替换当前未保存工作状态。清空会移除全部拼豆内容。缩小画布可能裁掉边界外内容。系统执行这些操作前必须二次确认，并在确认信息中说明具体影响。没有未保存内容或没有数据损失风险时，可省略确认。

### 6.2 编辑对象和共同约束

所有拼豆编辑工具仅修改唯一拼豆层。拼豆层锁定时，修改类工具不可执行。用户当前选中的 MARD 颜色是画笔、填充、换色、形状和文字工具的目标颜色。

画布中的空格以无拼豆状态保存，不属于任何颜色。

### 6.3 画笔与橡皮

画笔用于在拼豆层写入当前颜色，支持连续绘制。橡皮用于清除拼豆层格子，支持单格和不同大小的圆形范围。

橡皮大小支持 0、0.5 和整数档位。数值越大，单次清除的格子范围越大。

交互备注 默认右键为平移。用户可切换为右键单格擦除，右键擦除不受橡皮大小影响。

### 6.4 填充与消除

填充将点击位置所在的四向连通同色区域替换为当前颜色。点击空格时，填充相连的空白区域。

消除提供三种业务范围。

| 模式 | 清除范围 |
| --- | --- |
| 同色连续 | 与落点同色且四向连通的区域 |
| 所有同色 | 拼豆层中与落点颜色相同的全部格子 |
| 连续块 | 与落点四向连通的全部非空格，不区分颜色 |

### 6.5 换色与吸管

换色用于替换图案中已有的某个颜色。系统将拼豆层中匹配的颜色替换为当前选中颜色，并反馈受影响的拼豆数。

吸管用于从画布读取可见拼豆的颜色，并将该颜色设为当前颜色。

交互备注 吸管成功取色后自动返回画笔工具。

### 6.6 移动、复制、粘贴和镜像

移动支持整张图案和局部连续块两种范围。局部连续块指点击位置所在的四向连通非空区域。系统限制移动结果在画布范围内，并避免破坏未选择的既有内容。

复制支持连续块和多选拼豆两种范围。多选模式的复制结果以已选格子的最小包围盒保存，复制内容包含其中的空格和有色格。

粘贴将剪贴内容放入拼豆层。镜像支持整张图案和局部连续块两种范围，支持左右和上下翻转，镜像基准为选中内容的包围盒。

交互备注 移动、粘贴和镜像提交前展示落点或变换预览。复制完成后可自动切换至粘贴工具。

### 6.7 几何形状

系统支持直线、矩形、正方形、椭圆、正圆、三角形和箭头。矩形、正方形、椭圆、正圆和三角形支持空心和实心。箭头支持单向、双向和粗箭头。

形状以当前颜色写入拼豆层。

交互备注 用户拖动确定起点与终点，松开后写入图案，拖动中展示预览。

### 6.8 文字图案

系统支持将中文、字母、数字和符号转换为拼豆格文字。用户可设置横排或竖排、文字高度和文字间距。默认文字为 `ABC`，默认高度 17 格，默认间距 1 格。

文字以当前颜色栅格化后写入拼豆层。

交互备注 文字工具激活时，可用滚轮调节文字高度。

## 7. 色卡与颜色管理

### 7.1 MARD 色卡

MVP 使用 MARD 常用 211 色色卡。图片生成、拼豆层调整和手工选色均使用该色卡。

每种颜色包含色号、颜色名称、HEX 值、RGB 值和色号分组。色卡支持全部查看及按色号分组筛选。

业务边界 MVP 不支持其他品牌色号、扩展色卡和跨品牌转换。

### 7.2 当前颜色和最近使用

当前颜色作为编辑工具的目标颜色。当前颜色信息展示色号、名称和 HEX 值。

系统维护最近使用颜色列表，默认包含 H7 和 H2。新选择的颜色置于列表首位，重复颜色去重，最多保留 7 种。通过最近使用列表选色时不改变列表顺序。

## 8. 图层管理

### 8.1 图层模型

MVP 中每个项目只有一个可编辑拼豆层。所有绘制、图片生成、颜色调整、用量统计、3D 预览和图纸导出都以该拼豆层为准。

导入照片或参考图以照片参考层呈现。照片参考层只用于生成和临摹，可调整显示、透明度、位置、缩放和上下层级，不保存拼豆格，也不计入用量。

### 8.2 图层操作

拼豆层支持显示、隐藏、锁定和解锁。MVP 不提供新增、复制、删除、重命名、排序、分组、混合模式和批量图层操作。

照片参考层可显示在拼豆下方或上方。拼豆层和照片参考层之间不发生颜色合成和材料累计。

业务边界 参考 Perler 的多拼豆图层数据可在导入旧 JSON 时合并为单一拼豆层。出现同格冲突时采用原项目最上层的可见颜色。

## 9. 参考图

### 9.1 参考图用途

用户可单独上传 PNG、JPEG 或 WebP 图片作为临摹底图或结果核对图。参考图不写入拼豆格数据，不参与用量统计、3D 预览和图纸导出。

### 9.2 参考图设置

参考图支持显示和隐藏、透明度、缩放、位置以及层级位置设置。层级位置可选拼豆下方或拼豆上方，默认透明度为 35%。

用户可重置参考图变换，恢复缩放为 1 和偏移为 0。

交互备注 参考图进入调整状态后可拖动位置，并通过滚轮或界面操作缩放。

### 9.3 参考图持久化边界

参考图文件只保留在当前浏览器会话。项目本地草稿和 JSON 编辑记录不保存原始图片文件，重新打开页面或导入 JSON 后需要再次选择参考图。

## 10. 拼豆层颜色调整

### 10.1 基础颜色调整

用户可对拼豆层应用亮度、对比度、饱和度、色温和色相调整。调整后的颜色重新映射到 MARD 常用 211 色色卡。

同一轮连续调整以调整开始前的拼豆层数据作为原始数据，避免每次滑动都基于上一帧结果重复计算。用户可重置本轮调整，或使用撤销回到更早版本。

### 10.2 颜色整理

颜色整理用于合并拼豆层中的相近颜色，减少碎色。用户可设置整理强度，系统完成后反馈变更的拼豆数量。

### 10.3 色数限制

用户可限制拼豆层可使用的最大颜色数，默认上限为 16 色。系统保留主要颜色，并将其他颜色映射到保留颜色。

### 10.4 快速效果

系统支持反色、灰阶和黑白效果。效果仅应用于拼豆层，结果重新匹配至 MARD 常用 211 色色卡。

业务边界 拼豆层锁定时，基础调整、颜色整理、色数限制和快速效果均不可执行。

## 11. 视图与预览

### 11.1 2D 画布视图

画布支持圆形豆和方形豆两种显示方式，默认使用圆形豆。用户可独立显示或隐藏网格、行列坐标、拼豆板边界、图层重叠提示和孤立拼豆提示。

坐标从 1 开始。拼豆板边界按 52 × 52 板尺寸展示。

### 11.2 画布导航

用户可缩小、放大和适配画布。画布支持鼠标滚轮缩放、平移工具拖动、空格键临时平移和鼠标中键平移。默认右键也可用于平移。

交互备注 缩放以指针位置为中心。平移范围受限制，避免画布完全离开可视区域。

### 11.3 位置与工具预览

桌面端鼠标悬停到画布格子时，系统展示格子坐标和色号。Pad 端在触控或手写笔接触、移动和选中格子时提供相同信息。橡皮、填充、消除、换色、移动、复制、粘贴、镜像、形状和文字在提交前提供作用范围预览。

### 11.4 3D 拼豆预览

系统根据拼豆层生成实时 3D 拼豆预览，并同步当前圆形或方形豆的显示选择。预览为空时展示空状态，预览区显示当前总拼豆数，并提供放大查看入口。MVP 保留参考 Perler 的现有 3D 表现，不增加实物尺寸、熨烫效果和材质模拟。

## 12. 用量统计与制作提示

### 12.1 用量统计

系统按唯一拼豆层中的最终拼豆格统计材料数量，并按颜色数量从高到低展示。每个非空格只计算一颗，不存在跨图层重复累计。每种颜色展示色号、颜色信息、拼豆数量和预计包装数。

概览区展示总颗数、颜色种数和预计总包数。照片参考层不参与统计。

### 12.2 包装数量估算

用户可设置每包拼豆数量，范围为 1 至 10000，默认值为 500。每种颜色需要的包数按该色颗数除以每包数量后向上取整，总包数为各颜色所需包数之和。

交互备注 加减控制以 500 为步长调整到相邻整档。

### 12.3 孤立拼豆提示

系统在拼豆层中检查孤立拼豆。某颗拼豆的上、下、左、右均为空时，判定为孤立拼豆。斜向相邻不参与判断。

系统展示孤立拼豆数量，并可在画布中高亮这些格子，为熨烫和实际制作提供检查提示。

## 13. 导入导出

### 13.1 图纸导出

MVP 支持导出单页 PDF 图纸。导出范围使用图案实际边界，图纸不提供分页和打印比例设置。用户可填写作品昵称和作者昵称。

导出图纸包含作品标题、尺寸、MARD 品牌、颜色数、总颗数、四周坐标、拼豆格、每格拼豆色号和色号数量合计。作者昵称存在时，显示在图纸标题区域。

作品昵称为空时，系统使用当前时间生成默认文件名。一个项目生成一个 PDF 文件。

业务边界 PDF 为单页图片式文件，目标输出约为 330 PPI。导出画布最长边限制为 12000 像素。MVP 不提供 PNG 图纸、A4 分页和实体拼豆板编号。

### 13.2 用量清单导出

系统保留参考 Perler 的 XLSX 用量清单导出。工作簿包含项目汇总工作表。

每张工作表包含项目名称、品牌、画布尺寸、总颗数、颜色数、每包数量，以及色号、颜色名称、HEX、数量和预计包数。

### 13.3 编辑记录导出

系统保留参考 Perler 的 JSON 编辑记录导出，包含项目版本、名称、画布尺寸、色卡版本、拼豆层、视图设置、拼豆板设置和时间字段。

JSON 用于本产品恢复可编辑作品，不承诺作为通用拼豆图纸交换格式。

### 13.4 编辑记录导入

系统仅接收 JSON 编辑记录。文件至少需要包含有效的画布宽高和格子数据。导入时，系统补齐缺失设置并兼容旧版单层项目数据。

无效或无法读取的文件不得覆盖当前项目。成功导入后，项目可继续编辑，并同步更新画布尺寸等关联状态。MVP 不承诺长期版本兼容，只保证当前版本和参考 Perler 既有 JSON 的必要兼容。

## 14. 中英文界面

系统支持中文和英文。默认使用中文，若浏览器本地保存过英文偏好，则恢复英文界面。

界面文案、工具名称和状态信息随语言切换。项目名称保持用户输入的原文。

## 16. 核心业务规则

| 编号 | 规则 |
| --- | --- |
| BR 1 | 每个项目只有一个可编辑拼豆层 |
| BR 2 | 图片生成和所有拼豆编辑工具写入唯一拼豆层 |
| BR 3 | 拼豆层锁定时禁止编辑 |
| BR 4 | 照片参考层不保存拼豆格，不参与用量、3D 和导出 |
| BR 5 | 用量按唯一拼豆层的最终非空格统计，每格只计算一颗 |
| BR 6 | 所有生成、调整和效果处理的颜色必须匹配 MARD 常用 211 色色卡 |
| BR 7 | 图片生成的高度由原图比例和目标宽度计算 |
| BR 8 | 孤立拼豆在拼豆层内按四向相邻关系判断 |
| BR 9 | 包装数量按每种颜色分别向上取整后再求和 |
| BR 10 | 自动保存和 JSON 编辑记录都不包含图片或参考图原文件 |
| BR 11 | 主页两个创作入口共享同一套工作区和图纸数据结构 |
| BR 12 | 每份图纸独立保存在当前设备，并按最近编辑时间排序 |
| BR 13 | Pad 与桌面端保持相同的功能、页面内容和视觉体系 |
| BR 14 | 首页和图纸空间是两个独立一级菜单，项目编辑统一进入工作区 |
| BR 15 | 项目完成状态由用户手工设置，不根据系统行为自动变更 |
| BR 16 | 项目预览中的色号消耗与工作区用量统计使用同一套计算规则 |
| BR 17 | 删除项目等敏感操作必须经过二次确认 |
| BR 18 | 新建、清空和缩小画布等可能造成内容丢失的操作必须说明影响并二次确认 |
| BR 19 | 拼豆层已有用户编辑时，重新生成图片必须二次确认 |
| BR 20 | MVP 不提供账号、云端存储、跨设备同步、作品分享和社区发布 |

## 17. 非功能要求

### 17.1 本地处理与隐私

图片转换、画布绘制、用量统计、3D 预览、项目存储和文件导出均在用户设备完成。MVP 不上传照片和项目数据。后续采用云端存储时，需要补充用户授权、隐私说明和数据删除规则。

### 17.2 性能

连续图片参数变化需要防抖。画布缩放、平移和绘制应保持连续反馈。3D 预览不得显著阻塞 2D 编辑。大尺寸作品的生成和导出性能受用户设备能力影响。

### 17.3 终端适配

产品主要支持 Pad 和桌面端。两端使用相同的信息结构、功能名称、视觉组件和作品数据，用户在不同终端看到的页面内容和功能范围应保持一致。

桌面端主要适配鼠标和键盘，支持悬停、右键、滚轮和快捷键。Pad 端主要适配触控和手写笔，使用点击、长按、双指缩放、双指平移和手写笔绘制承接对应能力。

任何核心功能都不能只依赖悬停、右键或键盘快捷键。Pad 端需要为这类功能提供可见按钮、长按菜单或手势入口。触控目标需要满足手指操作，画布绘制需要区分单指绘制与双指导航，降低误触风险。

横屏作为 Pad 工作区的主要使用方向。竖屏仍需完整展示主页、图纸列表和核心功能，工作区可通过面板收起、底部工具栏或分区切换适配较窄空间。

### 17.4 视觉一致性与可用性

Pad 与桌面端使用一致的颜色、字体、图标、间距规则、卡片样式和状态反馈。允许根据屏幕尺寸调整布局、面板位置和工具呈现方式，但不能改变功能名称、业务含义和核心视觉识别。

图标按钮应提供明确名称。当前工具、拼豆层、当前颜色和开关状态应有可见选中态。无效操作应被禁用或提示原因。

敏感操作需要清楚展示操作对象和结果。确认窗口中的取消操作应保持安全状态，不能默认选中危险操作。

## 18. MVP 范围结论

| 项目 | MVP 结论 |
| --- | --- |
| 产品名称 | 正式名称使用 Pocket Pin |
| 项目存储 | 只使用设备本地存储 |
| 账号与同步 | 不提供账号和跨设备同步 |
| 图纸空间 | 支持搜索、完成状态筛选、重命名、复制、预览、编辑和删除 |
| 未完成生成 | 退出或失败时由用户确认是否保留 |
| 色卡 | 只使用 MARD 常用 211 色 |
| 敏感操作 | 新建、清空、缩小画布、覆盖生成和删除按影响范围二次确认 |
| 图片覆盖 | 未编辑的照片生成项目可直接写入，已有编辑时需要确认 |
| 拼豆层 | 只有一个可编辑拼豆层，照片作为辅助参考层 |
| 用量 | 按拼豆层最终非空格统计，每格只计算一颗 |
| 图层高级能力 | 不增加多拼豆层、混合模式、分组和批量处理 |
| 图纸导出 | 生成单页 PDF，显示逐格色号和色号数量合计 |
| 3D 预览 | 保留参考 Perler 的现有能力 |
| JSON | 保留现有导入导出，不承诺长期版本兼容 |
| 图片预处理 | 保留参考 Perler 现有能力，不新增裁剪、旋转、自动抠图和手动取背景色 |
| 原图与参考图 | 保留参考 Perler 的会话内使用方式，不随项目完整持久化 |
| 删除恢复 | 不提供回收站，二次确认后永久删除本地项目 |
| 分享与社区 | 不提供分享、链接预览、水印和社区发布 |
