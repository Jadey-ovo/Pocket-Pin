# PRD-Pocket Pin

更新时间：2026-10-10

本文是 Pocket Pin 唯一的产品需求主文档。后续需求直接修改对应章节，并在文末追加修订记录，不再为每轮迭代新建 PRD。历史正文通过 Git 追溯；测试结果统一记入 [验证记录-H5编辑器](验证记录-H5编辑器.md)。本文区分当前产品要求和后续范围，不将历史设想视为已上线功能。

## 1. 产品定位与范围

Pocket Pin 是将图片转换为 MARD 色号拼豆图纸的 H5 工具，提供手工编辑、材料统计和导出。手机、Pad 浏览器为主要入口，桌面浏览器兼容鼠标与键盘操作。采用 Vue 3 与统一的暖纸色、棕色文字、薄荷绿视觉体系。

图片处理、生成、编辑、统计和导出均在设备本地完成，不上传照片。当前不提供账号、云端保存、跨设备同步、社区、交易或公开分享链接。

主流程为选择图片、调整构图、生成预览、确认应用、手工细调、查看材料与导出。空白创作与照片导入共用同一工作区和项目模型。

## 2. 图纸空间与项目管理

首页提供“导入照片”“创作图纸”两个入口，并集中展示图纸空间。两个入口未按下时保持对齐，悬停仅提亮，按下保留反馈。

- 导入照片选择 PNG、JPG/JPEG 或 WebP 后进入构图流程，不直接覆盖已有图纸。
- 创作图纸创建默认 52 × 52 的空白作品。
- 图纸列表保留预览原始比例，按最近编辑时间排序，支持名称搜索与全部、待拼、已拼筛选。
- 项目菜单支持继续编辑、预览/导出、改名、复制、删除；完成状态由用户手工维护。
- 改名不改变图案。复制生成独立标识，并复制可恢复的原图数据。删除经确认后移除项目及关联原图，不提供回收站。
- 空状态继续保留两个创作入口。

## 3. 图片生成

### 3.1 输入与构图

图片类型在本地初判为卡通/插画或照片/写实，用户可更改。卡通默认 52 格，照片默认 100 格。输入图片保持原始比例，直接拖动调整位置、拖动四角等比缩放，框外保留可见原图边界以判断裁切。支持旋转。

构图以方形生成区域为基准，框内生成图纸。生成结果留有透明边距，尺寸标注应区分图案格数与包含边距的最终豆板尺寸。编辑豆板尺寸范围为 8–180 格。

导入主流程只保留构图、旋转、图案大小和图片类型。取消前置手动色数限制、去背景、修豆与整体预览入口，生成后再使用编辑工具和减少用色细调。

### 3.2 生成算法与用色

所有输出颜色必须来自应用内 MARD 211 色色卡，不生成虚构色号。

- 照片使用 OpenCV 保边平滑与边缘检测，并对检测到的人脸区域增加权重，保护小面积人物特征和深色细线。
- 卡通保留原始线条几何与抗锯齿，采用单格主色判断，不套用照片预处理造成描边增粗。
- 使用感知色差匹配与自动相近色归并，兼顾主体辨识度和杂色控制。色数是上限，不要求凑满上限。
- 相同版本、相同图片像素、相同构图和参数的输出应可复现；算法升级、尺寸、模式或构图变化可以改变色号。
- 核心生成在 Worker 中执行，参数更新防抖，过期结果不能覆盖最新预览。生成时展示状态，失败保留重试入口，禁止应用过期结果。

历史的“52 格目标宽、24 色上限、默认卡通”已被以上默认策略替代。去背景和自选色卡的历史规则不再作为当前导入流程的必备入口。

### 3.3 预览、应用与原图恢复

先构图，再由用户发起生成。预览不写入项目，确认应用才进入历史和保存。已有内容被替换时提示影响并确认；锁定图纸禁止写入。

原图和生成参数保存到设备 IndexedDB，支持重新打开后重调或换图。取消换图恢复原来源。原图不参与用量和最终图纸导出；JSON 编辑备份不承诺包含原图文件。

## 4. 编辑与历史

每个项目只有一个可编辑拼豆层。空格表示无拼豆，不属于任何颜色。锁定时禁止修改。

- 画笔、橡皮和矩形填充使用本次操作草稿，取消恢复，确认保存。
- 一次笔触一次撤销；操作态内撤销逐笔修改，保存后项目历史可撤销整次操作。项目历史保留最多 40 个快照，新修改清空重做。
- 连续绘制补齐经过的格子，pointercancel 或捕获丢失取消未完成操作。
- 填充采用拖拽矩形，松手提交；旧版连通填充描述不作为当前填充按钮定义。
- 换色先在豆板选择原色，再选择目标色，支持单颗、四向相连同色、全图同色；支持豆板取色、色卡和相近色推荐，以及修改前后对照。
- 选区收紧到实际拼豆边界，填色作用于已选豆子。移动、复制显示落点预览，禁止破坏选区外已有内容。
- 镜像支持水平与垂直预览，确认后提交。尺寸调整支持预览与锚点，缩小可能裁切时说明影响。
- 减少用色支持保护关键色、前后对照，保护色数量超过上限时提示。
- 清空保留尺寸和参考图，经确认执行，可通过撤销恢复。

## 5. 色卡、参考图与数据

首次进入网站显示本地保存说明弹窗，说明图纸仅存于当前设备与浏览器、不会自动跨设备同步、分享网站链接不公开图纸，按 1、2、3 点展示，并提醒清理网站数据及无痕模式的数据丢失风险，建议重要作品及时导出图纸。用户确认后在当前浏览器记录已读状态，后续进入不重复提示。

色卡提供本图用色、最近使用、全部、色系筛选和色号搜索，色号按自然顺序排序。初始颜色 H7，最近颜色初始为 H7、H2。桌面横向色条可拖动，拖动不能误触选色；触屏保留原生横向滚动。

参考图用于临摹和核对，可调透明度、缩放、位置与显示，默认透明度 35%。透明度滑块左侧提供显隐按钮；关闭仅隐藏参考图，不清除照片、位置或透明度。确认保存后，显隐状态随作品持久化，保持显示时可切换画笔在参考图上描画。取消调整恢复进入前的设置。参考图不保存拼豆格，不参与用量或导出。参考图设置与生成原图是不同用途，不将所有照片一概限定为会话内有效。

旧多层项目按可见层合成为单层，保留原始图层备份，隐藏层也须存在于备份；旧 v1 存储原文不覆盖。

项目按份独立保存。提交修改后调度保存，页面隐藏或 pagehide 时冲刷。保存失败不能假报成功，保留 JSON 备份入口；单个坏项目不阻止其他作品打开。撤销只恢复图案与尺寸，不覆盖后来修改的名称。

## 6. 画布、手势与布局

浏览工具单指拖动；画笔、橡皮单指绘制。任意工具支持双指缩放与平移，第二指加入时回滚未完成笔触；只剩一指仍继续导航，全部抬起才恢复编辑。核心功能提供可见按钮，不依赖悬停、右键或隐藏手势。

缩放围绕双指中心或滚轮指针。画布按视口绘制，仅渲染可见格子，不按全图放大尺寸分配位图。屏幕格宽支持 0.25–96 CSS px。小于 12 CSS px/格时，触摸编辑先放大目标位置，再次触摸才绘制。

| 格宽 | 显示规则 |
| --- | --- |
| 小于 6px | 连续色块，隐藏网格 |
| 6–12px | 主格线渐显，5 格辅助线从 8px 渐显 |
| 12–24px | 单格线渐显，线宽保持设备像素级；圆豆可显示 |
| 28px 起 | 可显示色号 |

网格支持自动、关闭、始终显示；52 格板界独立开关。标尺从 0 开始，密度自适应。支持适配画布与图案内容、圆豆与方豆显示，当前默认方豆和自动网格。

豆板与底部操作区保持稳定，分类切换不造成豆板跳动；色板、设置、导入与用量采用浮层。窄屏工具栏可横向滚动，撤销重做保持可达。只对画布等手势区域设置 touch-action:none，普通面板保持滚动，不禁止整页缩放。

按钮圆润并使用统一图标，主要操作提供按压反馈，选中态清晰。新设计触控目标至少 44px，图标按钮提供可访问名称；减少动态效果偏好下关闭非必要动画。中文与英文切换保留用户输入的作品名称原文。

## 7. 用量与导出

用量按最终非空格统计，每格一颗，参考图不计入。列表展示色号、颜色、颗数和包消耗，支持按颗数排序。每包默认 500 颗；整数采购包数按各色分别向上取整后求和，不能与小数形式的包消耗混淆。

当前主要导出入口提供 PNG/JPG。导出引擎保留 PDF 图纸、XLSX 清单与 JSON 编辑备份能力，不将底层能力视为所有界面都已提供入口。

- 图纸按实际图案范围输出，包含标题、可选作者、尺寸、逐格色号、坐标和用量。
- 基础格线为白色，每 5 格细红线、每 10 格粗红线。
- 支持可选的 45°平铺文字水印和透明度调节；预览与输出共享设置。
- 导出预览支持 1–8 倍缩放、双指缩放、放大后拖动、桌面滚轮、加减按钮及复位。导出预览双击放大/复位不改变画布编辑手势规则。
- 大图输出限制位图尺寸与内存。XLSX 包含项目汇总和色号用量，JSON 用于恢复可编辑作品，无效导入不得覆盖当前项目。

## 8. 后续范围与已替代设想

以下能力保留为后续候选，不属于本轮交付承诺：复杂几何形状、文字图案、3D 成品预览、亮度/对比度/饱和度/色温/色相调整、反色/灰阶/黑白等高级效果、孤立豆高亮、拖放和剪贴板图片导入、打印分页与比例控制。

不增加多拼豆层、混合模式、分组和高级图层批处理。账号、同步、社区和交易另行立项；不能因旧 PRD 曾提及就视为当前需求。

以下旧规则已明确替代，不再保留为另一份生效 PRD：Pad/桌面优先改为手机/Pad 优先；原图只在会话内使用改为本地 IndexedDB 保存；禁止 PNG/水印改为支持图片导出与可选水印；坐标从 1 改为从 0；旧独立首页/图纸空间定位合并为首页集中承载创作与图纸管理；仅 PDF 输出不再适用。

## 9. 验收要求

类型检查、自动化测试与生产构建通过后再发布。验证记录注明日期、测试范围、结果及未覆盖项，不把需求描述当作验证结论。

生成验收覆盖稀有特征色、卡通线宽、透明像素、平坦区域杂色、真实 OpenCV 运行；编辑验收覆盖取消/确认、两层历史、双指切换、锁定与保存失败；导出验收覆盖用量、格线、图纸尺寸与预览。

真实 iOS Safari、iPadOS Safari、Android Chrome 的双指手感、软键盘、系统返回、浏览器工具栏伸缩与下载仍需真机验收。桌面尺寸模拟不能替代真机；未测量不得宣称达到 60fps。当前测试与部署证据见验证记录。
