# 产品规划-Pocket Pin

本文件承载未实现方向与候选，不是现有产品能力说明，也不是工程实施授权。当前功能见 [PRD](PRD-Pocket-Pin.md)，代码与入口差异见 [仓库结构设计](设计说明-仓库结构.md)。

## 已确认方向，尚未实施

继续完善现有 H5，核心创作流程稳定后验证商业化机会，当前不迁移原生技术栈。尚未确定收费功能、价格、会员权益或推出时间。

视觉改版参考用户提供的拼豆大王与醒图截图，以作品为主、布局直观、控件克制，减少可爱装饰、厚描边、立体按钮和大面积奶油色。黑白灰与少量强调色为候选表达，具体布局和色值须通过后续设计确认。此方向不描述现有页面，也不代表本轮开展 UI 改版。

## 历史功能要求与当前缺口

以下来自此前 PRD 或调研，已从现有功能说明中移出。保留来源，不因移出而默认取消，也不在本轮自动实现。

| 内容 | 当前处理 |
| --- | --- |
| 原图和生成参数恢复、换图取消后恢复原来源 | 现有工具函数不足以证明用户能完成恢复；后续需决定入口与恢复范围。 |
| 参考图跨重新打开恢复 | 当前恢复链路存在缺口；保留历史预期，后续独立处理。 |
| 最近用色、本图用色独立入口 | 当前主色板只提供色系、全部、搜索及换色推荐，是否恢复旧入口待定。 |
| 减少用色、保护关键色与对照 | 存在旧实现，但当前主操作入口未闭合，是否重新提供待定。 |
| 锁定图纸、独立显示设置、尺寸对齐锚点 | 不把旧面板当作现有入口；当前可用调整见 PRD。 |
| PDF、材料表格、可编辑备份和原始图层备份 | 引擎或旧组件存在不等于用户可用；格式和入口需另行明确。 |
| 校对设为空白与撤销 | 当前校对入口未提供，历史要求保留待后续决定。 |
| 图例数量加减按钮 | 当前为直接数字输入；旧要求不作为当前功能。 |
| 导出按图案边界裁剪、作者设置 | 当前按整块豆板导出，无作者入口；旧要求另行评估。 |

## 尚未采纳的候选

复杂几何形状、文字图案、3D 预览、图片调整和效果、孤立豆高亮、拖放与剪贴板导入、打印分页与比例控制，均保持候选状态。

库存、制作计划与逐色辅助、智能板、账号同步、社区和交易来自历史调研，不属于本轮范围。详细研究保留在 [Beadmaster 调研](调研计划-Beadmaster产品重构.md)，不在本文件复制其方案。

## 纳入后续工作的规则

明确需求与产品取舍后，在对应 Issue 中确认范围；必要设计先于工程实施。已实现并有用户可用入口的行为才进入 PRD，未实现目标继续留在本文件或对应 Issue。
