# Pocket Pin H5 编辑体验迭代

确认日期 2026-09-07。本文是原还原版 PRD 的已确认修订，冲突内容以本文为准。

## 产品与范围

手机和 Pad 浏览器为主要入口，桌面浏览器保留基础兼容。保留 Vue 3，动森视觉通过统一组件主题实现。本轮主流程是选照片、调尺寸与用色、预览、应用、手工编辑、导出。

仅一个可编辑拼豆层，照片参考仅在当前会话使用。旧多层项目以可见层合成迁移，同时保存原始图层备份，v1 存储原文不覆盖。隐藏图层必须存在于备份中。复杂形状、文字、3D 与高级特效后续实现，不放在本轮常用工具栏。

## H5 手势

- 浏览工具单指拖动；画笔、橡皮单指绘制。
- 任意工具双指缩放和平移；第二根手指加入时回滚当前未完成笔触。
- 双指只剩一指时继续导航，全部抬起才恢复编辑。
- 一次笔触一次撤销，快速绘制补齐格子。pointercancel、丢失捕获取消未完成操作。
- 撤销、重做、适配、整体预览全部使用可见按钮。不实现双击、多指点按、长按快捷操作。
- 仅画布 touch-action:none，普通面板保持滚动。不设置禁止页面缩放的 viewport 参数。
- 小于 12 CSS px/格时，触摸编辑先放大目标位置，再次触摸才绘制。

## 缩放渲染

画布按视口尺寸绘制，缩放值连续，屏幕格宽支持 0.25–96 CSS px。缩放中心保持在双指中心/滚轮指针处。仅渲染可见格子，不按全图放大尺寸分配位图。

- 小于 6px 隐藏网格，使用连续色块。
- 6–12px 渐显主格线；5 格辅助线从 8px 渐显。
- 12–24px 渐显单格线，线宽保持设备像素级。
- 28px 起可显示色号，圆豆在 12px 起显示。
- 网格提供自动、关闭、始终显示。坐标位于边缘，密度自适应；52 格板界独立开关。
- 适配整张画布与适配图案内容两个入口。

## 生成和用色

图片变化与参数变化防抖 320ms，Worker 执行匹配，过期结果不可覆盖最新预览。采用每格 3×3 采样，卡通取主色，写实取平均色，结果匹配 MARD。预览不写项目，应用才写入历史和保存；覆盖现有内容须确认。

目标宽默认 52 格，保持原图比例，最长边不超过 180 格。极端长宽比允许短边小于 8 格，以避免拉伸。编辑尺寸调整仍为 8–180 格。

色数上限默认 24，提供快捷档位和滑块；实际色数单独显示。可限制允许使用的 MARD 色号。减少用色支持保护关键色、修改前后切换，保护色数量超过上限时明确提示。

色板包含本图用色、最近、全部与搜索。换色支持单格、四向相连同色、全图同色，先预览范围与目标颜色再应用。普通填充为连通同色填充。矩形填色/清除归于选区操作。移动、复制显示落点预览，避免覆盖选区外已有拼豆。

## 布局与视觉

手机与 Pad 竖屏采用底部工具与面板，Pad 横屏采用侧边面板。面板占据布局空间，不覆盖画布；半展开和展开由可见按钮控制。撤销重做永远可见。

暖纸色、棕色文字、薄荷绿、圆润字体。按钮胶囊轮廓，工具按钮圆角 20–22px；触控目标不小于 44px。主要动作有轻微叠层阴影，卡片无阴影。工具使用统一 22px 图标配短文字，熟悉操作可只显示图标并带可访问名称。图标沿用现有工具图形并统一容器，不强制全部纯文字。此项遵循用户后续明确调整。

## 保存和交付

笔触提交后调度单项目保存，显示待保存、已保存、失败；pagehide 和页面隐藏时冲刷。存储失败不能假报成功，保留 JSON 备份入口。坏项目独立跳过，不阻止其他作品打开。

正式图纸为 PDF，保留 PNG 便捷输出，用量为 XLSX，可编辑数据为 JSON。图纸按实际内容范围输出，包含格号、色号与用量。参考照片不计入统计和导出。

## 实施与验收

1. 数据模型、旧图层备份、分项目存储。
2. 视口渲染、基础手势、按笔触历史、自适应网格。
3. 生成预览、色数控制、自选色卡、选区与换色。
4. 动森主题、手机与 Pad 布局、图标和触控区域。
5. 自动化边界检查、浏览器实际操作、导出验证。

真实 iOS Safari、iPadOS Safari 与 Android Chrome 的触控和性能属于真机验收，桌面浏览器尺寸模拟不能替代。默认目标接近 60fps，未经过真机测量不得宣称已达标。
